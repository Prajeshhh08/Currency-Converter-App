# Currency Converter (USD to INR)

A simple Flutter application that converts United States Dollars (USD) to Indian Rupees (INR).

## Features
* **Manual Conversion:** Enter the amount in USD and press the "Convert" button to see the result in INR.
* **Clean Interface:** A straightforward UI designed for clarity and ease of use.
* **Cross-Platform:** Compatible with Android, iOS, and Web

## How to Run
1. Clone this repository.
2. Run `flutter pub get` in the terminal to install dependencies.
3. Use `flutter run` to launch the app on your emulator or device.
